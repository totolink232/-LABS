2.3. Логічні оператори та розгалуження:

  • null || 2 || undefined → 2 (перше істинне значення)
  • alert(1) || 2 || alert(3) → виведе 1, потім 2 (alert(1) повертає undefined, після чого повертається 2)
  • 1 && null && 2 → null (перше хибне значення)
  • alert(1) && alert(2) → виведе 1, потім undefined (alert(1) є undefined, на ньому зупиняється)
  • null || 2 && 3 || 4 → 3 (пріоритет у &&: 2 && 3 дає 3, далі null || 3 || 4 дає 3)
  • if (-1 || 0) alert('первое') → виведе 'первое' (-1 є truthy)
  • if (-1 && 0) alert('второе') → не виведеться (0 є falsy)
  • if (null || -1 && 1) alert('третье') → виведе 'третье' (-1 && 1 дає 1, це truthy)

2.4. Значення і типи виразів:

  • "" + 1 + 0 → "10" (string)
  • "" - 1 + 0 → -1 (number)
  • true + false → 1 (number)
  • 6 / "3" → 2 (number)
  • "2" * "3" → 6 (number)
  • 4 + 5 + "px" → "9px" (string)
  • "$" + 4 + 5 → "$45" (string)
  • "4" - 2 → 2 (number)
  • "4px" - 2 → NaN (number)
  • 7 / 0 → Infinity (number)
  • " -9\n" + 5 → " -9\n5" (string)
  • " -9\n" - 5 → -14 (number)
  • 5 && 2 → 2 (number)
  • 2 && 5 → 5 (number)
  • 5 || 0 → 5 (number)
  • 0 || 5 → 5 (number)
  • null + 1 → 1 (number)
  • undefined + 1 → NaN (number)
  • null == "\n0\n" → false (boolean)
  • +null == +"\n0\n" → true (boolean: 0 == 0)
