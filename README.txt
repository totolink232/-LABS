Лабораторна робота №4: Робота з модулями (ES6+)

Як запустити і перевірити:
1. Запустити файл start.bat
2. На сторінці видно, що текст змінився на новий (це робота модуля domUtils.js).
3. Перейти у вкладку Console. Там будуть виведені результати завдань 1 і 2


Файли проєкту:
- mathOperations.js - модуль математичних дій (завдання 1)
- user.js - модуль з класом користувача (завдання 2)
- domUtils.js - модуль для зміни тексту на сторінці (завдання 3)
- app.js - виклики функцій для завдань 1 і 2
- main.js - підключення domUtils та зміна тексту на сторінці
- index.html - головна сторінка
- start.bat - запуск локального сервера (python)
